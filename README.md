# 💬 Feedback App

A simple React application for collecting and displaying user feedback.

This project was created as a **React training project** to practice working with component state, event handling, conditional rendering, and reusable components.

## 🔗 Live Demo

[View Live Demo](https://goit-react-hw-02-plum-two.vercel.app/)

## 📌 About the Project

Feedback App allows users to leave feedback and displays the collected results in real time.

The application demonstrates how React state can be used to store user interactions and automatically update the interface when the state changes.

The project focuses on practicing the core principles of React and building a UI from reusable components.

## ✨ Features

* Leave positive, neutral, or negative feedback
* Display feedback statistics
* Calculate the total number of feedback responses
* Calculate the percentage of positive feedback
* Update the interface dynamically
* Reset and manage application state
* Conditional rendering when no feedback is available
* Responsive interface

## 🚀 Getting Started

To run the project locally:

```bash
git clone https://github.com/AleksandraCherevko/goit-react-hw-02.git
cd goit-react-hw-02
npm install
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```
